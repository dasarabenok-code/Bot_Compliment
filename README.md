#  Telegram-бот "Комплимент"

Простой Telegram-бот на Python, который приветствует пользователей и отправляет комплименты.

## 📋 Описание

Бот разработан в учебных целях для изучения:
- Python и библиотеки pyTelegramBotAPI
- Работы с Telegram Bot API
- Основ разработки ботов
- Безопасного хранения токенов (secrets.py)

##  Технологии

- **Язык:** Python 3.13
- **Библиотеки:** pyTelegramBotAPI (telebot)
- **IDE:** PyCharm
- **Контроль версий:** Git + GitHub

## 🚀 Функционал

- Команда `/start` — приветственное сообщение
- Безопасное хранение токена в отдельном файле `secrets.py`
- Отправляет разные комплименты пользователю
